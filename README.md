# New Life Clinic — сайт-лендинг

Одностраничный конверсионный сайт гинекологической клиники **New Life Clinic** (Алматы).
Построен вокруг врача — Исмаиловой Гульжахан Жолдасовны (акушер-гинеколог, эндокринный
гинеколог, 24 года практики). Запись на приём ведёт в WhatsApp.

## Технологии
Чистый статичный сайт: `HTML` + `CSS` + `JavaScript`, без сборки и зависимостей.
Деплоится на Vercel как статика.

## Структура
```
clinic-site/
├─ index.html      — разметка страницы (шапка + 5 блоков + футер)
├─ styles.css      — оформление (палитра, шрифты, адаптив, анимации)
├─ script.js       — анимации появления + сборка WhatsApp-ссылок
└─ images/
   ├─ doctor-hero.jpg
   └─ doctor-about.jpg
```

## Что заменить на реальные данные

**1. Контакты и WhatsApp** — файл [`script.js`](script.js), блок `CONFIG` в самом верху:
```js
const CONFIG = {
  whatsappNumber: "77000000000",  // номер WhatsApp в формате 77XXXXXXXXX
  phone: "",                      // телефон для звонка, напр. "+7 700 000 00 00"
  instagram: "https://www.instagram.com/mamin_doctor/"
};
```

**2. Адрес и часы работы** — файл [`index.html`](index.html), секция «Контакты»
(найдите тексты «адрес уточняется» и «часы работы»).

## Раздел услуг
На сайте указана **только одна цена** — акционный чекап **39 000 ₸**.
Остальные направления показаны без цен (заявка/стоимость уточняется в WhatsApp).

## Локальный просмотр
Откройте `index.html` в браузере двойным щелчком.
